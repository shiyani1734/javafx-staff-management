This project is a Java-based application developed for CSE 360 Individual Homework 4 (HW4), implementing the Staff role as a graphical user interface using JavaFX. The application allows staff users to perform basic CRUD operations on other staff users, including viewing the staff list, adding new staff members, and deleting existing ones. All staff data is stored in the same database used in the TP3 submission and managed using the existing DatabaseHelper class. The graphical interface (StaffHomePage.java) is built to be simple and user-friendly, featuring buttons for each action and a table for displaying user data. The logic for managing staff data is encapsulated in StaffManager.java, which handles all interactions with the database. The application includes full internal documentation and Javadoc output, following the same standards used in TP3. Unit tests for the Staff role functionality are provided in StaffTest.java and were written using JUnit 5. These tests verify that staff can be added and deleted correctly and ensure that the system behaves as expected. To run the program, the project can be opened in Eclipse, and staff users can log in to access the Staff Home Page. All features and testing confirm that the HW4 requirements have been fully met.
